# Command-Free AI – No-Code Custom AI Chatbot Builder

## 📌 Overview

Command-Free AI is a no-code custom AI chatbot builder that allows users to create intelligent chatbots from their own documents without requiring programming knowledge.

The application uses Retrieval-Augmented Generation (RAG), LangChain, and Large Language Models (LLMs) to provide context-aware responses based on uploaded documents.

## 🚀 Key Features

- 🤖 Create custom AI chatbots without coding
- 📄 Upload and process documents
- 🔍 Retrieval-Augmented Generation (RAG)
- 🧠 LangChain-based document retrieval
- 💬 Context-aware chatbot conversations
- 🌐 Web-based chatbot interface
- 📊 Dashboard for chatbot management
- 🔐 User login functionality
- 🐳 Docker support

## 🛠️ Technologies Used

- Python
- FastAPI
- LangChain
- Retrieval-Augmented Generation (RAG)
- Large Language Models (LLMs)
- HTML
- CSS
- JavaScript
- Docker
